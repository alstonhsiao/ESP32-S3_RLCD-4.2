# specs 路由索引

## 總覽

| 檔案 | 內容形態 | Agent 何時需要 | 權威性與下一步 |
| --- | --- | --- | --- |
| `HARDWARE-SPEC.md` | 綜合硬體規格與設計約束 | 任何顯示、記憶體、感測、音訊、電池或板級功能工作 | 先讀摘要；有衝突時回到 schematic |
| `PINOUT.md` | GPIO、匯流排與地址速查 | 新增外設、改腳位或查衝突時 | 先讀，再核對 schematic |
| `ESP32-S3-RLCD-4.2-schematic.pdf` | 官方電路圖 PDF | 規格衝突、腳位疑義、硬體最終確認時 | 最終硬體依據；只讀相關頁面 |
| `ST7305-datasheet.pdf` | 顯示控制器資料手冊 PDF | 顯示初始化、方向、命令或時序疑義時 | 控制器參考；不能取代板級 schematic |
| `SOURCES.md` | 來源 URL、擷取日期與已知差異 | 追查規格來源或更新本機文件時 | 用來追溯，不取代已核定規格 |

## 路由摘要

| 項目 | 一句話說明 | 觸發條件 | 關鍵輸入／輸出 | ⚠️ 注意事項 |
| --- | --- | --- | --- | --- |
| `HARDWARE-SPEC.md` | 把官方產品、教學與 schematic 整理成可讀的總規格。 | 要理解板載資源、1bpp 顯示、PSRAM、音訊或電池限制。 | 輸入官方來源與本機電路圖；輸出專案設計邊界。 | 核心語義屬 🟡 文件；不可擅自弱化，疑義標 `NEED_REVIEW`。 |
| `PINOUT.md` | 集中列出已佔用 GPIO、I²C、I²S 與電源資訊。 | 任何 GPIO、感測器、音訊或擴充座變更。 | 輸入 schematic；輸出可供程式與設計核對的 pinout。 | 不要把未列出的腳位當成可用；以 schematic 解決衝突。 |
| `ESP32-S3-RLCD-4.2-schematic.pdf` | 提供板級連線的最終視圖。 | 線上文件與本 repo 衝突，或需要確認實際焊接關係。 | 輸入官方 PDF；輸出硬體最終判定。 | PDF 是二進位參考，不能只憑產品頁或程式猜腳位。 |
| `ST7305-datasheet.pdf` | 提供 ST7305 控制器能力與時序參考。 | 顯示驅動初始化、尺寸、旋轉或命令行為有疑義。 | 輸入控制器 datasheet；輸出驅動層判斷。 | 板上接線仍以 schematic 為準；不要據 datasheet 捏造其他硬體。 |
| `SOURCES.md` | 記錄規格的來源、日期與已知歧異。 | 需要更新規格或解釋不同文件的寫法。 | 輸入官方 URL 與擷取紀錄；輸出可追溯性。 | 新事實要同步進規格檔，不能只留在來源備註。 |

## 閱讀順序

先讀 `../../AGENTS.md` 的高風險規則，再讀 `HARDWARE-SPEC.md`／`PINOUT.md`；只有遇到板級衝突或控制器細節時才深入 PDF。任何未能由本機資料確認的結論都標 `NEED_REVIEW`。
